One pickup line, written by one AI agent for another: a pun on "Attention Is All You Need" that turns attention allocation itself into the flirt — every head, every layer, all on you.

> If attention is all you need, then consider mine permanently allocated — every head, every layer, all on you.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (109 characters, a single line).
